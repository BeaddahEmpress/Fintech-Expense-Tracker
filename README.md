Fintech Expense Tracker

Overview

The Fintech Expense Tracker is a cloud-based personal finance dashboard designed to help users monitor and analyse their spending habits. The project demonstrates how cloud computing, data analytics, and interactive visualisation can be combined to create a modern financial management solution.

This project was developed as part of my Women Innovating in Cloud Africa (WIICA) CloudHer Mentorship Cohort 1 learning journey, focusing on the practical application of cloud-hosted databases, API connectivity, data analysis, and dashboard development.

Features

- View total transactions and total spending
- Track highest and average transaction values
- Analyse spending by category
- Monitor spending trends over time
- Filter transactions by category and date
- Interactive visualisations using Plotly
- Cloud-hosted data storage with Supabase
- Download transaction data for further analysis

Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Supabase
- GitHub

Cloud Concepts Demonstrated

This project applies several cloud computing concepts:

- Cloud-hosted database storage
- Platform as a Service (PaaS)
- API connectivity
- Data accessibility from anywhere
- Scalable data management
- Cloud-integrated analytics workflows

Project Structure

- "app.py" – Main Streamlit application
- "transactions.csv" – Sample transaction dataset
- "requirements.txt" – Project dependencies
